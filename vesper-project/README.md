# Vesper

A dark, living landing page: one field of 91,000 particles that breathes as
an orb, blows open into a ring galaxy, gathers into the Earth with real
coastlines, and finally aligns into the letters "AI" — driven by scroll,
answering every move of the cursor.

## Quick start

Open `index.html` in any browser. That's it — three.js and the Earth land
mask are inlined, so it works offline.

## Editing

1. Edit `src/vesper.src.html` (readable source).
2. Rebuild the self-contained file:

   ```bash
   python3 build.py
   ```

3. Open `index.html` again.

See `CLAUDE.md` for the architecture map — if you open this folder with
Claude Code, it reads that file automatically and knows its way around.
